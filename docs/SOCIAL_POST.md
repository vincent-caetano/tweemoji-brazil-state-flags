# Social launch copy

## Post em português

Sua cidade merece um lugar no próximo app que você construir. 🇧🇷

Criei um projeto open source com as bandeiras dos 26 estados + Distrito Federal, redesenhadas no estilo Twemoji: SVGs editáveis e PNGs transparentes, prontos para usar em interfaces.

Agora quero construir a próxima parte com outros software builders: as bandeiras das nossas cidades.

A meta é chegar às 5.571 localidades brasileiras — 5.569 municípios, Brasília e Fernando de Noronha — uma contribuição por vez. Onde existir uma bandeira oficial, queremos uma versão pequena, reconhecível e bem feita para usar nos nossos projetos.

Quer colocar sua cidade no mapa?

1. Escolha sua cidade e confira se alguém já está trabalhando nela.
2. Copie o prompt do repo, troque o nome da cidade e a UF e entregue ao seu coding agent.
3. Revise o resultado: referência oficial, SVG original e leitura em tamanho pequeno.
4. Envie um PR. Seu crédito fica junto da contribuição.

O prompt já orienta o agente a pesquisar, desenhar, exportar, validar e abrir o PR pelo seu fork. Também deixei templates de issue e PR para facilitar a revisão.

Se essa comunidade crescer, a próxima etapa pode ser levar o projeto para estados e cidades de outros países.

Vamos espalhar nossas bandeiras pelos READMEs, apps e projetos do GitHub — e fazer uma primeira contribuição open source no caminho.

## Nota editorial

O objetivo de 5.571 se refere a localidades: 5.569 municípios, Brasília e Fernando de Noronha. [IBGE explica a classificação](https://educa.ibge.gov.br/jovens/materias-especiais/22754-um-pais-com-quase-seis-mil-municipios.html). Não implica que todas tenham bandeira oficial, nem que todas as contribuições já existam. A expansão internacional é uma possibilidade futura.

Twemoji é a referência de estilo; este projeto é independente e suas bandeiras não são novos emojis Unicode. O post é um rascunho para você publicar; nenhum conteúdo foi enviado a redes sociais.
