# Flag accuracy review

Reviewed 7 October 2026. These are original interface illustrations, not official heraldic reproductions. The shared rounded 36×36 canvas changes official aspect ratios; colors use the collection palette. Fine inscriptions, dates inside crests, botanical details and decorative linework are reduced or omitted.

## Remaining interpretation limits

- Amazonas retains 62 stars (61 small plus the larger central star), matching the current reference. Exact municipal placement is normalized; legal verification of the recent revision remains open.
- Tiny heraldic inscriptions are omitted in the six detailed crests. The leaf shapes and landscape scenes are symbolic, not botanical or geographic drawings.
- Text on ES, MG, PR and PI is path geometry and becomes decorative at the smallest preview sizes.
- São Paulo's Brazil map is an approximate hand-drawn silhouette. Tocantins uses sixteen simplified broad rays.
- The palette is optimized for screens; it does not reproduce official print specifications.

Please report accuracy issues with a state code, an official source, and the affected detail. Change the source geometry in `scripts/build.py`, then rebuild and export; do not patch generated files alone.
